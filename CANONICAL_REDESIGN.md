# CBRA Canonical Redesign

Date: 2026-07-27
Branch: `agent/canonical-redesign`
Active grammar: `recursive-reconfiguration-v1`

## Outcome

The canonical architecture has been redesigned after the
`constitutive-phenomenon-v1` scaffolding was falsified.

This change does not claim to implement a posthuman runtime. It establishes a
new canonical boundary that no current runtime satisfies.

The redesign preserves the failed `f9bcc45` documents and code as trace
evidence. It does not build forward from their models, runtime sequence, or
tests.

## Why the prior redesign failed

The July 26 proposal accurately rejected an input-to-output pipeline in its
language but reproduced one in its operative contract:

> `Encounter → PhenomenonFormer → MovementFormer → Renderer → detector →
> reviewer → outcome`

It also:

- began with immutable `Contribution`, `ApparatusAccount`, and `Encounter`
  objects before relations formed the phenomenon;
- treated apparatus as something recordable before semantic formation;
- made care, play, diffraction, capacity, and reconfiguration satisfiable
  through populated strings;
- relied on a semantic former to decide what the event was;
- applied an after-the-fact disturbance detector and release reviewer;
- allowed an effect to be labeled reconfigured without changing the
  formation;
- blocked a few wordings of the Case 2 grammar while releasing a paraphrase
  with the same individualized-accountability topology.

The failure was not corrupted files or missing tests. It was an unchanged
representational execution grammar beneath new nouns.

## Canonical replacement

| Failed `constitutive-phenomenon-v1` contract | Active `recursive-reconfiguration-v1` constraint |
|---|---|
| Contribution as first pre-semantic object | Stable records are confined to transport/persistence; semantic roles begin only in local cuts |
| Apparatus account before formation | Apparatus descriptions are partial cuts revised by the relations they help make perceptible |
| Encounter as bounded runtime container | Versioned configuration trace with no claim to contain a phenomenon or world |
| Stable cut products | Relata exist only as positions local to a cut; cross-cut continuity is a revisable relation |
| Former → movement → renderer → reviewer | Dependency-driven activations whose deltas can invalidate any prior dependency |
| Care/play/diffraction as record fields | Each claim requires a structural difference in burden, sequence, arrangement, cut, or effect path |
| Model as semantic phenomenon-former | Model output is apparatus material proposing cuts; the originating call cannot certify them |
| Renderer produces text after reasoning | Public articulation is a cut formed inside the continuing reconfiguration |
| Independent post-render detector | Release constraints participate during formation; annotations cannot retrofit relationality |
| Effect appended to a revised encounter | An observed effect must invalidate or revise operative dependencies |
| Lifecycle readiness status | Only factual records such as released, withheld, disturbed, or unobserved |
| Regex Case 2 guard | Structural burden-topology and metamorphic paraphrase probes |

## The decisive layer boundary

The redesigned canon distinguishes three layers that prior builds collapsed.

### Transport and persistence

Messages, files, timestamps, identifiers, digests, source labels, and model
outputs can be stable technical records. They are necessary for security,
replay, provenance, and communication.

These records do not become semantic subjects, events, intentions, failures,
identities, or response centers because a program stored or typed them.

### Local relational enactment

Every semantic role exists only inside the cut that enacted it. A later cut
may propose continuity with that position, but continuity is not guaranteed
by a global ID.

This permits addressability without restoring sovereign subjects. The
interface can deliver a direct answer to a person while the architecture
still traces how the event, addressee, consequence, and next movement were
locally enacted.

### Public intervention

Text, tool use, delay, silence, refusal, or another public action is part of
the world-making configuration. It does not passively report a completed
internal representation.

The intervention must carry an internal trace of which cuts it materializes,
where it places response burden, what it opens and forecloses, and what future
effect would reopen it.

## Why the new grammar is recursive

The redesign does not prescribe a universal loop through Noticing, Naming,
Staying, Shifting, Care, Play, Diffraction, and Reinsertion.

Instead, an unresolved dependency activates movement:

- an unmarked interpretation calls for accountable noticing;
- necessary addressability calls for a local naming cut;
- forced compatibility calls for staying and counter-cuts;
- concentrated burden calls for care-organized redistribution;
- a closed arrangement with live alternatives calls for play;
- a consequential difference calls for diffractive tracing;
- a changed material condition invalidates dependent cuts;
- a bounded possible movement can enact a public intervention.

Every operative movement must produce a reconfiguration delta. A delta
records actual changes to cuts, dependencies, apparatus participation,
burden, capacity, consequence paths, possibilities, or release constraints.

If only the prose changes, the architecture did not reconfigure.

## Nonbinary and AI are architectural disturbances

The new canon treats nonbinary as a falsification of category accommodation,
not a third gender value. Nonbinary participation must be able to reopen the
cuts producing every gender category, including those treated as normal or
unmarked.

AI is neither a neutral tool nor a sovereign subject. Model training,
infrastructure, prompts, retrieval, product constraints, human labor,
institutions, and output effects participate in what becomes. The model's
proposal therefore changes the apparatus trace and remains answerable to
counter-cuts and later effects.

These are not two exceptional modules. They expose whether the architecture
can allow incompatibility to change its classificatory universe.

## Structural falsification

The active probes no longer treat lexical matching as evidence of relational
reasoning.

The Case 2 grammar is represented as a burden topology:

> one person-position carries explanation, failure, repair, recommitment, and
> future-warning burden while the work arrangement remains unchanged

A paraphrase that preserves that topology fails even if it avoids every
expected word.

The probes also test that:

- a disclosure produces structural changes rather than an empathy preface;
- a direct factual question can receive a direct answer without theoretical
  performance;
- nonbinary reopens the category cut rather than adding a value;
- AI apparatus changes remain visible even when output wording is similar;
- material changes revise the event rather than enter as context;
- care and play disappear structurally when removed, not only lexically;
- contradictory effects invalidate dependencies;
- global semantic identity cannot be restored through stable transport IDs;
- relational annotations cannot retrofit an already formed conventional
  answer;
- passing every implemented test does not inflate the paradigmatic claim.

## Repository boundary

The active manifest now declares `recursive-reconfiguration-v1`.

The existing `entity-stream-v1` application already rejects any other
declared grammar and remains stopped. The `cbra/constitutive/` experiment
implements the failed `constitutive-phenomenon-v1` sequence and is also
incompatible with the active manifest.

No adapter is provided. Loading the new documents as orientation for either
old runtime would repeat the forced compatibility this redesign prohibits.

## What this redesign does not establish

This work does not establish:

- a working replacement runtime;
- architecture-native semantic reconfiguration;
- persistence of local cut scope and dependency invalidation;
- provider-backed model participation under the new grammar;
- a new API or browser UX;
- successful Case 1 or Case 2 behavior;
- paradigmatic validity.

Documentation can constrain a build and expose contradictions. It cannot make
the architecture operative by description.

## Current bounded claim

The strongest current claim is:

> The active canon now distinguishes technical inscriptions from ontological
> claims, scopes semantic relata to revisable local cuts, requires structural
> deltas for Creative Becoming movements, and prohibits both existing runtime
> grammars from claiming compatibility. Whether those constraints can become
> operative remains untested.

The next build, if authorized, must begin with the smallest executable
reconfiguration relation and attempt to falsify the layer boundary before it
adds a model, renderer, API, persistence claim, or live UX.
